1️⃣ QuickSort là gì?

Tư duy cốt lõi: Divide & Conquer (Chia để trị)

  • Chọn Pivot: Lấy 1 phần tử làm mốc chia mảy.
  • Phân hoạch: Đẩy phần tử < Pivot sang trái, ≥ Pivot sang phải.
  • Đệ quy: Lặp lại trên 2 mảng con cho đến khi kích thước ≤ 1.

2️⃣ Chiến lược chọn Pivot

Tiêu chí Lomuto Hoare
Vị trí Cuối cùng arr[r] Đầu tiên arr[l]
Độ phức tạp Đơn giản, 1 vòng lặp 2 con trỏ, phức tạp hơn
Hiệu năng Nhiều swap hơn ~20% nhanh hơn

3️⃣ Cơ chế Phân hoạch (Partition)

🔵 Lomuto Partition

  • 1 con trỏ i làm ranh giới vùng < Pivot
  • Duyệt tuần tự j từ l → r-1
  • Nếu arr[j] ≤ pivot → i++, swap arr[i] ↔ arr[j]
  • Kết thúc: đặt pivot vào i+1, trả về vị trí

🔴 Hoare Partition

  • 2 con trỏ i (trái), j (phải) ngược chiều
  • i tiến đến khi arr[i] ≥ pivot
  • j lùi đến khi arr[j] ≤ pivot
  • Nếu i < j → swap cặp sai vị trí
  • Dừng khi i ≥ j, trả về j làm ranh giới

4️⃣ Độ phức tạp (Complexity)

Trường hợpTimeSpaceGhi chú
Tốt nhất / TB O(n log n) O(log n) Pivot chia đều. In-place, cache-friendly.
Xấu nhất O(n²) O(n) Mảng đã sorted + Pivot cố định (đầu/cuối).

🔵 Partition_Lomuto


int Partition_Lomuto(int l, int r) {
    int pivot = arr[r], i = l - 1;
    for (int j = l; j < r; j++) {
        if (arr[j] <= pivot) {
            ++i; swap(arr[i], arr[j]);
        }
    }
    swap(arr[++i], arr[r]); // Đặt pivot
    return i;
}

🔴 partition_Hoare


int partition_Hoare(int l, int r) {
    int pivot = arr[l], i = l - 1, j = r + 1;
    while (true) {
        do { ++i; } while (arr[i] < pivot);
        do { --j; } while (arr[j] > pivot);
        if (i < j) swap(arr[i], arr[j]);
        else return j;
    }
}
